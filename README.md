# 收藏夹同步

适用于 Microsoft Edge / Chrome 的收藏夹同步扩展。通过你自己的 GitHub 或 Gitee 仓库同步收藏夹，无需使用发布者的同步服务器。

## 功能

- 同步收藏夹、目录层级及顺序，同目录相同网址保留靠前项，跨目录相同网址保留。
- 记录新增、删除、移动、改名和排序，按操作时间与已知依赖合并双方修改。
- 缺少的浏览器系统分类转换为收藏夹栏末尾的普通文件夹。
- 手动同步、可选自动同步、本地 JSON 备份与恢复。

在所有设备上使用相同平台、账号和仓库名。默认仓库名称固定为 `bookmark-sync`。首次新建仓库默认为私有；已有公开仓库的可见性不会自动改变。

访问令牌仅保存在本机，并用于所选平台的 API 认证。收藏及操作记录存储在你指定的仓库中。同步 JSON 不进行端到端加密；请注意仓库可见性和 Git 历史的保留。

先修改后删除则删除；先删除后修改则恢复。原父目录已删除时恢复到“同步恢复”。使用多台设备时请保持时钟正确。恢复 JSON 备份会新建独立恢复文件夹，保留现有收藏。
